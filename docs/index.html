IaC Secret Scanner

Lightweight static scanner that searches infrastructure and configuration files for common exposed-secret patterns. Symbolic links are excluded and files remain local. It produces machine-readable JSON and a non-zero exit code when matches are detected.

Source codeDocumentation
01 / COVERAGE

Configuration files

Terraform, YAML, JSON, shell, TOML, INI and environment files.

02 / DETECTION

Heuristic patterns

Recognises common cloud-key prefixes, private-key headers and plaintext secret assignments.

03 / INTEGRATION

CI-friendly output

JSON output and exit codes support use as a simple pipeline gate.
